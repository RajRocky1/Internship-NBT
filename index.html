Phase 01 · Foundation

MediCare Hospital

Healthcare Website
Problem
A hospital needed a digital front door — departments, doctor profiles, services and appointment enquiries — that worked cleanly on every device.
My role
Owned the full frontend build: markup, styling, responsive layout and interactive interface elements.
Constraints
Internship timeline, self-directed build, no CMS — every section had to be hand-structured.
What I built
A responsive multi-section hospital site with healthcare department listings, doctor profiles, service pages and an appointment enquiry interface.
Result
A complete, responsive hospital website with interactive UI elements — the foundation pattern reused in later builds.
Learned
How to structure content for a service-driven site, and why responsive-first thinking changes layout decisions early.

Looking Back

What This Internship Taught Me

A short reflection on growth, process, and what comes next.

Before this internship, I thought building a website was mostly about making it look right. Three projects later, I understand it's about making it work right — for the person on the other side of the screen. MediCare taught me to structure content for a real service. StayNest taught me that data shapes the interface as much as design does. DBG Gastro Care taught me to adapt those patterns to a specialized, high-trust domain.

If I did this again, I'd document my decisions earlier and test on real devices sooner — both would have saved rework. Next, I want to go deeper on the backend: moving from MySQL queries toward full API design.
